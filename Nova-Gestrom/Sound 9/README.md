# Experiment 9 - Weather Dashboard

Two terminals are required.

Backend:
```bash
cd backend
npm install
npm start
```
Backend URL: http://localhost:5000/weather/chennai

Frontend (second terminal):
```bash
cd frontend
npm install
npm run dev
```
Open the Vite URL, normally http://localhost:5173. Select Chennai, Mumbai or Delhi.
The lab manual's city weather values are sample/static data, not live external weather data.
