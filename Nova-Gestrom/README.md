# Nova-Gestrom

Practical programs 1–10. Open each Experiment folder and follow its README.

Requirements: Node.js LTS, npm, Git, VS Code, Postman and MongoDB for database experiments.

Experiments:
1. Node.js setup and GitHub
2. Movie REST API
3. Online bookstore with HTTP, timers and events
4. Server uptime monitor
5. Food delivery menu CRUD
6. Users and orders relationship
7. JWT authentication
8. Blogging CRUD API
9. Weather dashboard with React Router
10. E-commerce product app with MongoDB Atlas
