# Experiment 1 - Node.js Environment and GitHub

Run:
```bash
npm install
npm start
```
Output: `Task Manager Project Initialized Successfully`

GitHub push commands from repository root:
```bash
git init
git add .
git commit -m "Added all experiments"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/Nova-Gestrom.git
git push -u origin main
```
Replace YOUR_USERNAME with your GitHub username.
